# Media Player & YouTube Setup
> **Note:** Scroll down for the Swahili version (Toleo la Kiswahili lipo chini).

This is a comprehensive media application that allows users to play audio, watch local videos, view images, and stream YouTube videos directly within the system. 

---

## 🇬🇧 English Version

### 🔥 Features
- **Audio Player:** Supports and plays various audio formats (e.g., MP3, WAV).
- **Video Player:** Plays local video files smoothly with high quality.
- **Image Viewer:** Allows users to open, view, and browse through images.
- **YouTube Integration:** Streams and plays YouTube videos directly using an internet connection.

### 📚 My Learning Journey (How I Built This)
This project was created as a hands-on learning experience to understand how modern media setups are architected and built. Through this project, I learned:
1. **Media Handling:** How software decodes and renders different file formats (audio frequencies, video frames, and image pixels).
2. **API Integration:** Connecting to external services like YouTube to fetch and stream online content in real-time.
3. **System Architecture:** How to structure code to handle multiple media types without causing system crashes or lags.
4. **Problem Solving:** Debugging issues related to media playback, buffering, and user interface responsiveness.

## 🇹🇿 Toleo la Kiswahili

Hii ni programu ya media inayomruhusu mtumiaji kucheza sauti (audio), kutazama video za ndani, kuangalia picha, pamoja na kurusha (stream) video za YouTube moja kwa moja kwenye mfumo huu.

### 🔥 Vipengele
- **Kucheza Sauti (Audio Player):** Inasoma na kucheza faili za sauti (kama MP3, WAV, n.k.).
- **Kucheza Video (Video Player):** Inacheza video za ndani (local videos) kwa ubora wa juu.
- **Kuonyesha Picha (Image Viewer):** Uwezo vya kufungua na kuonyesha picha mbalimbali.
- **YouTube Integration:** Inatafuta na kucheza video kutoka YouTube kupitia mtandao.

### 📚 Safari Yangu ya Kujifunza (Nilivyotengeneza Mfumo Huu)
Mradi huu umetokana na safari yangu ya mafunzo kwa vitendo ili kuelewa jinsi mifumo ya kisasa ya media inavyoundwa na kufanya kazi. Kupitia mradi huu, nimejifunza:
1. **Usimamizi wa Media:** Jinsi programu inavyosoma na kuonyesha mifumo tofauti ya faili (frikwensi za sauti, fremu za video, na saizi za picha).
2. **Uunganishaji wa API:** Jinsi ya kuunganisha programu na mifumo ya nje kama YouTube ili kupata na kucheza video mubashara (real-time).
3. **Muundo wa Mfumo (Architecture):** Jinsi ya kupanga kodi ili kuendesha aina tofauti za media bila kulemaza au kukwamikwama kwa mfumo.
